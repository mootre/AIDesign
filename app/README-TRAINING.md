# อ่านดี Training Studio

เว็บฉบับใหม่แยกจาก ThaiFurnitureAnalyzer เดิม ใช้พอร์ต 8768 สำหรับผู้ใช้เครื่องที่เชื่อถือได้

## เปิดใช้งาน

1. ดับเบิลคลิก start.bat โปรแกรมจะเปิด http://127.0.0.1:8768/training
2. ถ้ายังไม่มี Python dependencies ให้รัน install.bat ก่อน หรือสร้าง .venv แล้วติดตั้ง requirements.txt
3. การทำเฉลยและเก็บชุดข้อมูลด้วยคนใช้ได้โดยไม่ต้องล็อกอิน AI ไม่มีการส่งข้อมูลออกโดยอัตโนมัติ
4. หากต้องการให้ AI ช่วยอ่าน ให้รัน codex login ด้วยบัญชี Windows ที่เปิดเว็บนี้ก่อน และอนุญาตส่ง AI ในสิทธิ์เอกสาร
5. หน้า / เป็นฉบับวิเคราะห์/OCR/CAD ที่อ้างอิงจากตัวอย่างเดิม ส่วนหน้า /training คือคลังข้อมูลที่เพิ่มใหม่ การแปลง CAD ยังต้องมีเครื่องมือ CAD ภายนอกตามตัวอย่างเดิม

start.bat ใช้ .venv ของโฟลเดอร์นี้ก่อน หากไม่พบและมี Python environment ของ ThaiPDFReader ตัวอย่างเดิมจะใช้ environment นั้นได้โดยอ่านอย่างเดียว ไม่แก้ข้อมูลโปรแกรมเดิม

## เก็บตัวอย่างแรก

1. ลงทะเบียน PDF ไม่เกิน 30 MB และ 200 หน้า กรอก code / revision / group เป็นรหัส A-Z a-z 0-9 ขีดหรือขีดล่าง
2. ใช้ group เดียวกันสำหรับแบบที่เกี่ยวข้อง ภาพย่อย และ revision ของตระกูลเดียวกัน ไฟล์ hash ซ้ำหรือ code เดียวกันห้ามอยู่คนละ group
3. ยืนยันสิทธิ์เก็บและปกปิดข้อมูลส่วนบุคคลก่อนอัปโหลด สิทธิ์ส่ง AI กับสิทธิ์ใช้ฝึกเป็นคนละ checkbox และเริ่มไม่เลือก
4. เลือกหน้าแบบ ระบุมุมมอง และลากกรอบหลักฐานบนภาพ กรอบเก็บเป็น normalized x,y,width,height อ้างกับภาพ PDF หน้าและ revision ที่เลือก
5. กรอกคำถาม คำตอบ หน่วย และประเภท direct / calculated / inferred / insufficient ถ้าเป็น calculated ต้องมีสูตรและคำอธิบาย ถ้า insufficient ให้เว้นค่าคำตอบและระบุสิ่งที่ขาด; ถ้าไม่มีกรอบจะใช้ทั้งหน้าปัจจุบันเป็นบริบท
6. บันทึกเป็น draft จากนั้นเลือกส่งเข้าคิวตรวจ และจึงยืนยันคำตอบด้วยรหัสผู้ทบทวนต่างจากผู้ทำเฉลย พร้อมยืนยัน privacy
7. กำหนด split train / dev / test ให้ทั้ง group กำหนดแล้วเปลี่ยนข้ามชุดไม่ได้
8. ส่งออก ZIP จะมี train.jsonl / dev.jsonl / test.jsonl, ภาพทั้งหน้าที่ใช้อ้างอิง และ manifest

ผล AI เดิมเก็บเป็น prediction แยก immutable ไม่เป็น gold label อัตโนมัติ การเลือกค่าผล AI เป็นเพียงจุดเริ่มตรวจ; ต้องทำเฉลยและตรวจรับเอง การแก้ annotation ที่อนุมัติแล้วเพิ่ม version และกลับเป็น draft

## ข้อมูลอยู่ที่ไหน

ค่าเริ่มต้นคือ %LOCALAPPDATA%\ThaiFurnitureTrainingStudio ประกอบด้วย SQLite และสำเนา PDF ที่ระบบตั้งชื่อด้วยรหัส ไม่มีการเก็บชื่อไฟล์เดิมเป็น path ตั้งค่า THAI_TRAINING_DATA ใน environment ของ process เพื่อใช้ไดเรกทอรี private อื่นได้ ต้องสำรองทั้ง SQLite และโฟลเดอร์ไฟล์ในช่วงที่ปิดโปรแกรม

ต้นฉบับไม่ถูกเขียนทับผ่าน API และตรวจ SHA-256 ก่อนแสดง/ส่งออก หากไฟล์เปลี่ยนจากภายนอกจะหยุดเพื่อป้องกันใช้หลักฐานผิด revision ประวัติ annotation และ consent เก็บเป็นรายการเพิ่มใหม่

ห้ามเก็บคลังข้อมูลจริง exports, auth, credentials หรือ .venv ลง Git/Docs Hub ห้ามใส่รหัสผ่าน ข้อมูลบัญชี หรือข้อมูลบุคคลในช่องคำตอบ มีตัวกรองข้อความบางรูปแบบ แต่ไม่ได้ปกปิดข้อมูลส่วนบุคคลในภาพให้อัตโนมัติ ผู้ใช้ต้องตรวจทั้งหน้า เพราะชุดส่งออกมีภาพทั้งหน้าไม่ใช่เฉพาะกรอบ

## เงื่อนไขส่งออก

รวมเฉพาะ annotation รุ่นปัจจุบันที่ approved, allow_training เป็น true, privacy ของแบบและคำตอบผ่าน, split ถูกกำหนด และไม่ใช่ inferred รายการ draft/submitted/rejected/changes_requested ถูกข้าม ไม่ส่ง reviewer identity ชื่อแบบ path เครื่อง ประวัติดิบ หรือผล AI ดิบใน JSONL

ZIP เป็น snapshot แบบ provider-neutral ไม่ได้เรียกฝึกโมเดลอัตโนมัติ การเก็บคำแก้ไขไม่ได้เปลี่ยน Codex ให้เรียนรู้ถาวรทันที ต้องแปลงข้อมูลตามโมเดลที่เลือกและประเมินกับชุดที่กันไว้ ห้ามนำชุด test ไปใช้ใน prompt หรือ retrieval ระหว่างประเมิน

การถอน allow_ai หรือ privacy จะหยุดงาน AI ที่ผูกกับเอกสารและปิดการถามต่อของงานนั้น การถอน allow_training จะตัดรายการออกจาก export ครั้งถัดไป ไม่สามารถเรียกคืนไฟล์ที่เคยส่งออกหรือทำให้โมเดลที่ฝึกไปแล้วลืมได้เอง

## ขอบเขตความปลอดภัย

รับเฉพาะ localhost ตรวจ Host และ token ของ session ในหน่วยความจำ และปฏิเสธ Origin จากเว็บอื่น รหัสผู้ตรวจเป็นเพียง workflow สำหรับผู้ใช้เครื่องที่เชื่อถือได้ ไม่ใช่ login และไม่พิสูจน์ว่าเป็นคนละคนจริง ห้ามเปิด LAN/Tunnel/Internet จนกว่าจะเพิ่มระบบ login และ authorization ที่ backend

AI ใช้ Codex CLI ที่ล็อกอินอยู่ ส่งเฉพาะภาพหน้าที่เลือก สูงสุด 8 หน้า พร้อมข้อความ PDF ไม่เก็บ auth ของ Codex ในแอป ปิด shell/connectors และใช้ read-only sandbox โดยไม่เขียน raw CLI transcript ลงไฟล์ รุ่น CLI ต้องรองรับ flags ที่ใช้ มิฉะนั้นจะวิเคราะห์ไม่สำเร็จ

## ตรวจโปรแกรม

python -m unittest discover -s . -p "test_*.py"

การทดสอบ CAD เพิ่มเติมต้องติดตั้ง requirements-dev.txt ใช้ synthetic PDF และ mock CLI เท่านั้น ไม่มีแบบลูกค้าหรือ AI inference จริงอยู่ในชุดทดสอบ

## สิ่งที่ยังไม่ยืนยัน

ยังไม่ได้ทดสอบการตอบจากโมเดลจริงในรอบนี้ และผู้ใช้หยุด Computer Use ด้วย Escape ระหว่างตรวจ Browser จึงยังไม่ยืนยันการลากกรอบและ layout บน Browser จริง ใช้ผลทดสอบ HTTP/SQLite/การเรนเดอร์ภาพและ syntax JavaScript เป็นหลัก ไม่ได้เชื่อมต่อการฝึกโมเดลจริง ระบบหลายคน หรือการให้บริการผ่านเครือข่าย
