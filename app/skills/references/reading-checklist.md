# Drawing Reading Checklist (fillable)

- [ ] Title/status/date/scale noted
- [ ] Furniture type and modules identified
- [ ] Spec callouts mapped to parts (material, thickness, finish, edge)
- [ ] Overall W x D x H read from Top + Elevation
- [ ] Sub-dimensions add up to overall
- [ ] Bays, shelves, drawers, rods counted from Inside view
- [ ] Wall gaps / scribe areas flagged
- [ ] Door types (glass vs MDF) confirmed
- [ ] Assumptions table completed and shown to user
- [ ] Waste % and edge-banding rule stated
- [ ] Items needing site measurement listed
