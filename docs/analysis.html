    วิเคราะห์ชิ้นส่วนและวัสดุ
    
      
    เทียบรูปด้านบน รูปด้าน และรูปตัดเพื่อยืนยันขนาดและจำนวน ระบุหน้าที่อ้างอิงและความหมายของตัวเลขก่อนนำมาคำนวณ
    
      
    
        หลักการอ่านแบบของ ThaiFurnitureAnalyzer
        
      
          
    1. ตรวจรุ่นของแบบ หน่วย สเกล และขนาดรวมกว้าง × ลึก × สูง จากมุมมองที่เกี่ยวข้อง
      2. 
          
    2. เทียบขนาดย่อยกับขนาดรวม นับชั้น ลิ้นชัก และอุปกรณ์จากภาพภายในหรือรูปตัด
      3. 
          
    3. จับคู่หมายเลขสเปกกับวัสดุ ความหนา ผิว และขอบของแต่ละชิ้น
      4. 
          
    4. บันทึกสิ่งที่อ่านตรง ค่าคำนวณ และสมมติฐานแยกกัน พร้อมหน้าและเหตุผล ถ้ายืนยันไม่ได้ให้เว้นค่า
      5. 
          
    5. ตรวจขนาดชนกัน ระยะติดตั้ง แนวลายไม้ รอยตัด และชิ้นที่เกินแผ่นก่อนสั่งตัด
      6. 
        
    
      
    
      
    ใช้ OCR และ Codex จาก โปรแกรมวิเคราะห์แบบในเครื่อง แล้วนำเข้าไฟล์ผลวิเคราะห์ JSON หรือกรอกชิ้นส่วนที่ตรวจแล้วด้านล่าง
